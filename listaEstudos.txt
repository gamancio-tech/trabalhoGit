O que é um branch?
Um branch ("galho", em inglês) é uma linha independente de desenvolvimento dentro do mesmo repositório. Ele
permite testar algo novo sem mexer na versão principal do projeto.
O branch main é, por convenção, a linha principal — a versão "oficial" e estável do projeto

O que é Controle de Versão de Código?
Imagine esta outra situação:
- Você trabalha em uma empresa onde os arquivos de programa ficam salvos no Dropbox;
- Você e um colega estão trabalhando no mesmo arquivo de programa, e baixam o mesmo arquivo;
- Você edita o arquivo, finaliza seu trabalho e salva no Dropbox;
- Seu colega edita o arquivo, finaliza o trabalho dele no final do dia e salva o arquivo no Dropbox,
sobrescrevendo seu arquivo.

O que é o Git?
Durante o desenvolvimento de um software* queremos saber:
- O que mudou?
- Quando mudou?
- Por que mudou?
- Quem fez a mudança?
- Podemos reproduzir esta mudança?

Pull Requests: pedindo revisão
Um Pull Request (PR) é um pedido para que as mudanças de um branch sejam revisadas e mescladas ao branch
principal. É assim que times profissionais revisam código antes de ele entrar no projeto oficial

O que é o Git Bash
Git Bash é um terminal que já vem instalado automaticamente junto com o Git para Windows. Ele simula,
dentro do Windows, o mesmo terminal ("Bash") usado nativamente por sistemas Linux e Mac.
Isso importa porque o próprio Git foi criado no mundo Linux — todos os tutoriais, toda a documentação oficial e
a grande maioria dos exemplos disponíveis na internet assumem que você está usando comandos no estilo Bash
(ls, pwd, mkdir, rm...). O Git Bash traz esse mesmo padrão para dentro do Windows, evitando ficar "traduzindo"
comandos toda hora.

Atalhos úteis do Git Bash
● Tab: autocompleta nomes de pastas, arquivos e até comandos — digite as primeiras letras e pressione
Tab
● Seta para cima (↑): repete o último comando digitado — pressione várias vezes para navegar pelo
histórico
● Ctrl + C: cancela o comando em execução ou limpa a linha atual
● Ctrl + L: limpa a tela (mesmo efeito do comando clear)
● Botão direito do mouse: cola o que estiver copiado (o Ctrl+V comum nem sempre funciona no Git Bash)
